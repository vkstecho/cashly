# Cashly by VKS Tech

Personal finance tracker PWA – expenses, budgets, SMS import, statements & tax tools.

**Short name:** Cashly  
**Full name:** Cashly by VKS Tech

## Firebase
Uses the existing Firebase project: `moneyflow-vkstech` (unchanged).

## Deploy
1. Upload everything inside this folder to your repo root (or `/docs`).
2. Enable GitHub Pages or host on any static server / Firebase Hosting.

## Features
- Axio-style UI (green theme, spent ring, categories, budget planner)
- SMS auto-import (Indian banks + UPI)
- Budgets, dues, credit cards, weekly summary
- Offline-first PWA
